# College crests

Drop a square PNG here named after the college's slug, for example
`iit-bombay.png`, then run `npm run logos`.

The slug is the college's short name in lower case with spaces turned into
hyphens: "IIT Bombay" is `iit-bombay`, "NIT Trichy" is `nit-trichy`,
"REC Ambedkar Nagar" is `rec-ambedkar-nagar`.

Anything not listed in `src/data/colleges/logos.ts` falls back to the drawn
monogram badge, which always renders, so this folder can stay empty.

Only add an image the institute publishes for this use. An institute's crest
is its trademark: do not scrape one off a page that does not offer it.
